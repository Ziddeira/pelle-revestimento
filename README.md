# Pelle Revestimentos — site

Site institucional em HTML, CSS e JavaScript puros, com animação de scroll em canvas usando a sequência de imagens em `frames/`.

## Estrutura

```
index.html
styles.css
script.js
frames/
  frame-001.jpg … frame-300.jpg
```

A pasta `frames/` precisa ficar ao lado do `index.html`. O padrão de nome dos arquivos é configurado no topo do `script.js` (`pad: 3` para `frame-001.jpg`, `pad: 4` para `frame-0001.jpg`).

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta com qualquer servidor estático.
